# User interface {#ch-ui}

## Lightning apps and navigation {#ui-apps}

Both applications are Lightning consoles for desktop:

- « Branch Console » (`NWB_Branch_Console`): customers, leads, loan applications, branches and the « New loan » tab; its home page is `Branch_Home`;
- « Contact Center » (`NWB_Contact_Center`): leads, customers and contact attempts.

## Lightning pages {#ui-pages}

| Page | Object | Custom components |
|---|---|---|
| `Account_Record_Page` | `Account` | `customer360` |
| `Loan_Application_Record_Page` | `LoanApplication__c` | `loanTimeline` |
| `Branch_Home` | Home page | Standard components only |

## Lightning Web Components {#ui-lwc}

### By domain {#ui-lwc-domains}

| Domain | Components | Role |
|---|---|---|
| Customer 360 | `customer360`, `positionTile` | Live positions of the customer |
| Loans | `loanTimeline`, `loanWizard` | Timeline of an application; creation wizard in a tab |

## Communication between components {#ui-communication}

- `customer360` reads its data with a cached wire adapter on `Customer360Controller` and passes each position to `positionTile` as a public property.
- `loanTimeline` uses Lightning Message Service; the channel `LoanSelected` is defined for selection events between components.
- `loanWizard` uses the navigation service to open the created application.
